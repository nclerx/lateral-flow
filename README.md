This repository contains the source code to run the lateral meltwater flow model described in "Modelling lateral meltwater flow and superimposed ice formation atop Greenland's near-surface ice slabs", Journal of Glaciology 2024: "1dflow_darcy.py".

The script "1dflow_darcy_runoff.py" is described in Chapter 6 of the PhD-thesis "Measuring and modelling firn hydrology in the accumulation zone on the southwestern Greenland Ice Sheet" (doi: 10.51363/unifr.sth.2024.010).
